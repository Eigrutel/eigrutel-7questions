# Changelog

Toutes les modifications importantes apportées à **7 questions** seront documentées dans ce fichier.

Le format s’inspire de [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/) et le projet suit le principe du [versionnage sémantique](https://semver.org/lang/fr/).

Les catégories utilisées sont :

- **Ajouté** pour les nouvelles fonctionnalités ;
- **Modifié** pour les changements apportés à des fonctions existantes ;
- **Corrigé** pour les corrections de bugs ;
- **Supprimé** pour les éléments retirés ;
- **Sécurité** pour les corrections liées à la sécurité.

## [1.0.0] — 2026-07-29

### Ajouté

- première version stable publique de **7 questions** ;
- interface bilingue français–anglais ;
- français utilisé par défaut lors de la première ouverture ;
- bouton de changement de langue **English / Français** ;
- mémorisation de la langue choisie dans le navigateur ;
- titre public commun **7 questions** ;
- sous-titre variable :
  - **Méthode QQOQCCP** en français ;
  - **5W2H Method** en anglais ;
- champ principal pour définir le sujet étudié ;
- sept rubriques d’analyse :
  - Qui ? / Who?
  - Quand ? / When?
  - Où ? / Where?
  - Quoi ? / What?
  - Combien ? / How much?
  - Comment ? / How?
  - Pourquoi ? / Why?
- champ de notes complémentaires ;
- aides contextuelles bilingues pour chaque rubrique ;
- verrouillage individuel des rubriques ;
- réduction et réouverture des cartes ;
- indicateur visuel de progression ;
- sauvegarde automatique dans le stockage local du navigateur ;
- export et import des fiches au format JSON ;
- export des fiches au format Markdown ;
- mise en page dédiée à l’impression et à l’export PDF ;
- interface responsive pour ordinateur, tablette et téléphone ;
- code source regroupé dans un fichier HTML autonome ;
- commentaires du code en français et en anglais ;
- en-tête de version, d’auteur et de licences intégré au fichier source.

### Documentation

- ajout du fichier `README.md` ;
- ajout du fichier `notice.md` ;
- ajout du présent fichier `CHANGELOG.md`.
